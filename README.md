# 勤怠自動入力ツール

このリポジトリは、業務を効率化していきたい思いから自社の勤怠管理Webサイトに対して **勤怠入力を自動化** するPythonツールを作成いたしました。
Seleniumを活用して、ブラウザ操作を自動で行い、平日の勤怠入力を効率化します。
今後精度を上げながら修正をしていく予定です。

## 機能

- 勤怠Webサイトへのログイン自動化
- 勤怠表の各行（平日のみ）を判定
- 平日の場合、自動で出勤・退勤時間を入力
- 勤怠入力ボタンのクリック操作

## 使用技術

- Python 
- Selenium　
- Chrome WebDriver

## 使い方

1. Python環境を用意する
2. 必要なライブラリをインストール
   pip install selenium
